# King of Skills AI — Platform

## Project Overview
King of Skills AI (kingofskills.ai) is a sovereign intelligence platform for ambitious business professionals, entrepreneurs, and founders who want to master the AI era. It delivers daily AI intelligence, master prompts, skill frameworks, and courses.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Deployment**: Vercel (planned)

## Project Structure
```
src/
  app/           # Next.js App Router pages
    api/         # API routes (subscribe, contact)
    about/       # Philosophy & about page
    academy/     # Courses listing
    newsletter/  # The King's Brief signup
    prompts/     # Daily Prompt showcase
  components/    # Shared UI components
  lib/           # Constants, utilities, types
```

## Key Commands
- `npm run dev` — Start development server
- `npm run build` — Production build
- `npm run lint` — Run ESLint

## Brand Guidelines
- **Colors**: Gold (#c9a84c) on dark (#0a0a0a) background
- **Voice**: Calm authority. Never hype. Specific over vague. Actionable over theoretical.
- **Handle**: @kingofskillsai
- **Nickname**: Kingo

## Content Architecture
Every piece follows three layers:
1. **The Philosopher** — question assumptions
2. **The Strategist** — connect to business impact
3. **The Craftsman** — deliver the tool/prompt/framework

## Product Stack
- Free: Newsletter, Daily Prompt, Social
- Paid: Prompt Bundle ($97-$297), Codex ($97-$197), Academy ($197-$497)
- Premium: Vault ($19/mo), Workshop ($49/session), Agency ($2K-$10K)
